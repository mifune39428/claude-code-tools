# Notion 空欄リサーチ 自動入力

Notionに「あとで調べる」とメモしておいた行の、**結果欄が空のところだけ**を
まとめて調べて埋めます。

## こんな人向け

- 気になったことをNotionにメモしておくが、調べるところまで行かずに溜まっている
- 溜まった分を、あとでまとめて片付けたい

## 必要なもの

- **Claude Code**（このスキルはClaude Codeの「スキル」として動きます）
- **ClaudeのNotion連携**（コネクタ）
- **APIキーは要りません。** Notionのインテグレーション作成も不要です

## 入れ方

1. `SKILL.md` をダウンロード
2. 自分のMacの `~/.claude/skills/notion-research-fill/SKILL.md` に置く
   （`notion-research-fill` というフォルダを作って、その中に入れてください）
3. Claude Code を開き直す

これだけです。

## 使い方

Claude Codeにこう言うだけです。

```
Notionの調べ物を埋めて
```

初回は「どのNotionページ／データベースを対象にしますか？」と聞かれるので、
対象のページを教えてください。2回目からは覚えているので聞かれません。

## 何が起きるか

1. 対象のデータベースから、結果欄が空の行だけを拾う
2. Web検索で調べる（複数まとめて並列で調べるので速い）
3. 300〜500字にまとめてNotionに書き戻す
4. 空欄が0件になったか確認して報告する

カテゴリ列があれば、内容に応じたタグも一緒に付けます。

## 気をつけていること

- **勝手にデータベースの構造を変えません。** 結果列が無いときは、作ってよいか必ず確認します
- 「〜って本当？」という形のメモには、結論を先に書きます。前提が間違っていれば正します
- 統計・価格・最新ニュースは必ず検索で裏取りします

## うまくいかないとき

- 結果列が見つからない → 列の型が「テキスト（rich_text）」になっているか確認してください
- 月別にデータベースが分かれている → 親ページを指定すれば、配下をまとめて処理します

Issue で教えてもらえれば直します。
